    Chicago Style

    这是芝加哥大学海德公园校区的三维数字孪生。“芝加哥风格”在这里落在四件事上：

    1. 视觉：配色取自芝加哥市旗。白色底，两道浅蓝代表密歇根湖与芝加哥河，红色六角星用来标出地标。
    2. 坐标：芝加哥统一门牌网格以 State 街与 Madison 街交口为原点，每英里 800 号，8 个街区。悬停任意位置即显示网格坐标，街名按芝加哥路牌样式绘制。
    3. 建筑：“风格”视图把学院哥特式、草原学派（罗比之家）、芝加哥现代主义与当代作品分开着色。
    4. 引注：说明文字的注释与下方参考文献按《芝加哥格式手册》的注释—参考文献体例书写。这本手册由芝加哥大学出版社出版。
